# Genealògic

App web (PWA) per crear i visualitzar el teu arbre genealògic. Funciona al mòbil, sense connexió i les dades es queden al teu dispositiu.

## Publicar a GitHub Pages
1. Crea un repositori nou (per exemple `Genealogic`).
2. Puja tots els fitxers d’aquest zip a l’arrel del repositori.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
4. Obre `https://EL-TEU-USUARI.github.io/Genealogic/` i, al mòbil, «Afegeix a la pantalla d’inici».

## Còpia de seguretat
Botó **Còpia**: copia les dades en JSON i guarda-les on vulguis; per recuperar-les, enganxa-les i prem **Carrega**.
